# dg-mobile_pad

안드로이드 휴대폰을 맥북·갤럭시 탭의 무선 트랙패드로 씁니다. 외부 서버나 API 없이 로컬에서만 동작합니다.

## 블루투스 트랙패드 앱 (권장)
휴대폰이 **블루투스 마우스+키보드**로 인식됩니다. 맥북이나 탭에는 아무것도 설치하지 않습니다.

- 요구사항: 안드로이드 9 이상 휴대폰. 갤럭시 S25 Ultra(안드로이드 17)에서 맥북프로와 갤럭시 탭으로 확인했습니다.
- 받는 쪽: 맥, 안드로이드 태블릿/폰 등 블루투스 마우스를 지원하는 기기. 아이폰·아이패드에서 조종하는 것은 iOS 제약으로 안 됩니다.

| 동작 | 방법 |
|---|---|
| 커서 이동 | 한 손가락 문지르기 |
| 클릭 | 탭 |
| 스크롤 | 두 손가락 위아래 |
| 뒤로 / 앞으로 | 두 손가락 ← / → (맥: ⌘[ ⌘], 안드로이드: 뒤로/앞으로 키) |
| 기기 전환 | 기기 카드 탭 (한 번에 한 기기) |

### 설치와 페어링
1. 휴대폰에 `trackpad.apk`를 설치합니다. 처음 한 번 "출처를 알 수 없는 앱"을 허용해야 합니다.
2. **앱을 먼저 연 다음** 오른쪽 위 ＋를 눌러 휴대폰이 다른 기기에서 보이게 합니다.
3. 맥(시스템 설정 > 블루투스)이나 탭(설정 > 블루투스)에서 휴대폰을 골라 페어링합니다.
4. 앱에서 그 기기 카드를 누르면 연결됩니다.

앱보다 먼저 페어링했거나 HID 형식이 바뀐 버전으로 업데이트했다면, 받는 기기는 휴대폰을 "휴대폰"이나 예전 형식으로 기억합니다. 이때는 받는 기기에서 휴대폰을 지우고 2번부터 다시 하세요.

### 빌드 (Docker, Gradle 없이)
```
docker build --platform linux/amd64 -t trackpad-build android
docker run --rm --platform linux/amd64 -v "$PWD/android":/app trackpad-build ./build.sh
```
- 결과는 `android/build/trackpad.apk`에 생깁니다. 빌드할 때 순수 Java 단위 테스트(`HidTest`, `TwoFingerTest`)도 같이 돌아갑니다.
- 서명 키 `android/debug.keystore`는 처음 빌드할 때 만들어지고, git에는 올리지 않습니다. 키가 바뀌면 기존 앱을 지워야 업데이트되니 따로 보관하세요.
- USB나 무선 디버깅으로 설치하려면 `adb install -r android/build/trackpad.apk`를 실행합니다.

## 웹 트랙패드 (블루투스 없이 Wi-Fi로)
휴대폰에 앱을 설치하지 않고, 맥에서 서버를 띄운 뒤 휴대폰 브라우저로 접속합니다. 맥에서만 쓸 수 있습니다.

```
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # 처음 한 번
.venv/bin/python -m gesture_mouse.remote            # 실제 커서 제어
.venv/bin/python -m gesture_mouse.remote --dry-run  # 커서는 안 움직이고 연결만 확인
```
1. 휴대폰을 맥과 **같은 Wi-Fi**에 연결합니다.
2. 터미널에 뜬 QR을 휴대폰 카메라로 찍거나, 주소를 Chrome에 입력합니다. 주소는 실행할 때마다 바뀝니다.
3. 맥에서 "Python이 들어오는 연결을 허용" 창이 뜨면 허용합니다. 커서를 움직이려면 터미널 앱에 **손쉬운 사용** 권한이 필요합니다.

| 동작 | 방법 |
|---|---|
| 커서 이동 / 클릭 | 한 손가락 문지르기 / 탭 |
| 드래그 | 두 번 탭한 뒤 두 번째 손가락을 떼지 않고 끌기 |
| 스크롤 / 우클릭 | 두 손가락 위아래 / 두 손가락 탭 |
| 유튜브 / 이전 / 음성검색 / 다음 | 화면 아래 버튼 (Safari) |
| 제어 켜기/끄기 | 오른쪽 위 ON/OFF |

- **접속 제한:** 실행할 때마다 새로 만드는 비밀 토큰이 든 주소로만 접속되고, 한 번에 휴대폰 한 대만 연결됩니다.
- **연결이 끊기면:** 즉시 버튼이 풀리고 제어가 꺼집니다.
- **주의:** HTTP라서 같은 Wi-Fi에서 트래픽을 엿보면 토큰이 보일 수 있습니다. 집 Wi-Fi에서만 쓰세요.

테스트(Docker):
```
docker build -f Dockerfile.test -t gm-test .
docker run --rm -v "$PWD":/app gm-test
```
